This repository contains vendored source code of open-source libraries.
Non-essential files such as examples, tests, benchmarks, documentation, CI configuration and unused backends have been removed for brevity.
Original license files and copyright headers in source files are preserved.

Removed: examples, tests, docs, CI, unrelated platform/renderer backends
License file: thirdparty/imgui/misc/LICENSE.txt
